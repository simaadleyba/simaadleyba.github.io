Model Selection and Explainability in Traffic Accident Severity Prediction

Oct 2025 – Jan 2026 Sima Adleyba, Başak Çarhacıoğlu, and Ahmet İhsan Gül

This project uses data from 101,904 U.S. police-reported crashes (CRSS, 2016–2023) to compare a class-weighted Linear SVM and an ordinal XGBoost model for four-class injury-severity prediction. We use SHAP, LIME, and DiCE to examine which features matter most to each model.

Overview

Problem

We inspect what the models consider important when classifying injury severity. The four classes are no injury, minor, severe, and fatal. Fatal crashes make up only ~2.4% of cases.

Dataset

101,904 police-reported U.S. crashes from the Crash Report Sampling System (CRSS, 2016–2023).

Models

We compared a class-weighted Linear SVM with an ordinal XGBoost model that divides the four-class task into three binary thresholds.

Explainability

SHAP for global feature attribution, LIME for local instance-level explanations, and DiCE for counterfactuals.

Takeaway

Both models reach ≈ 0.59 accuracy and 0.53–0.54 macro-F1. Oversampling lifts fatal-class F1 from 0.26 to 0.59. Feature reduction does not improve performance.

02 | Dataset

Dataset & task

The Crash Report Sampling System (CRSS) contains U.S. police-reported crash records. The raw data are organized in 28 relational tables.

101,904 crashes in the full dataset
163 crash-level features
28 relational source tables
40.9% of records contain an unknown indicator

We combined information about vehicles, drivers, and occupants into one record per crash. Counts, proportions, summary statistics, and indexed fields such as TRAV_SP_1 and TRAV_SP_2 make up the features. We used MAX_SEV, the highest injury severity in the crash, as the target. Its four classes are 0 for no injury, 1 for minor injury, 2 for severe injury, and 3 for fatal injury. Possible injuries are included in the minor class.

We kept separate indicators for missing values (_UNKNOWN) and fields that did not apply (_NOT_APPLICABLE). These indicators can affect the predictions. The models use a feature set designed to avoid leakage. LIME and DiCE use a separate imputed version of the data for explanations.

We applied SMOTE only to the training split. It increased the share of fatal crashes from 2.38% to 5.38%, without fully balancing the classes. We then compared models trained with and without oversampling.

Class distribution with held-out test split

0: no injury 48.87%
1: minor 37.69%
2: severe 11.08%
3: fatal 2.37%

The splits include about 71K training, 15K validation, and 15K test crashes.

04 | Methodology

We used fixed train, validation, and test splits and compared models with and without oversampling. We aggregated explanations over a fixed evaluation subset, then retrained models with fewer features and evaluated them on the held-out test set.

05 | Models

Linear SVM

  • We used balanced class weights because fatal crashes account for about 2.4% of records.
  • We scaled numeric features, encoded categorical features, and tuned C on the validation set.
  • The linear SVM had the highest macro-F1 among the linear models in the initial comparison.
  • We produced separate SHAP and LIME explanations for each severity class.

Ordinal XGBoost

  • We trained three binary classifiers for P(y≥1), P(y≥2), and P(y≥3).
  • Each classifier used early stopping on the validation set and scale_pos_weight for its class distribution.
  • We calculated four-class probabilities from the cumulative predictions: P(y=0)=1−p₁, P(y=1)=p₁−p₂, P(y=2)=p₂−p₃, and P(y=3)=p₃. We selected the class with the highest probability.
  • This setup accounts for the order of the severity classes.
06 | Explainability

Explainability

We used SHAP to examine feature importance across the models, LIME to inspect individual predictions, and DiCE to see which feature changes alter predicted severity.

We used mean absolute SHAP values to compare feature importance. For XGBoost, we calculated them separately for each ordinal threshold. Features with high importance include NMACTION_NA, VEH_COUNT, GVWR_AVG_1, ALCOHOL, DRDISTRACT_1, and TRAV_SP_*. For the SVM's fatal class, TOTAL_COUNT and NMOTHPRE_UNKNOWN increase the prediction, while REGION and the 45–60 age share decrease it.

This comparison uses the 20,000-crash subset from the progress report.

We removed the *_UNKNOWN indicators from the XGBoost model to see how the explanations changed. With those indicators, the fatal-threshold model relies heavily on fields such as NMHELMET_UNKNOWN and NMACTION_UNKNOWN. Without them, ALCOHOL becomes more prominent. Macro-F1 falls from 0.45 to 0.44 on this subset.

XGBoost SHAP for the fatal threshold P(y≥3), before / after removing *_UNKNOWN features: progress report, Model 8 vs. Model 8′ (20k subset).

We used an imputed version of the data for LIME explanations. We aggregated XGBoost LIME weights over 89 fixed evaluation cases. VTRAFWAY_4, PEDESTRIAN_COUNT, and P_CRASH1_4 appeared most often. For the SVM, we inspected explanations for individual cases by severity class.

We generated three DiCE counterfactuals for each of 20 fatal test crashes to see which feature changes moved their predictions away from fatal. For XGBoost, P_CRASH1_2, MANEUVER_1, and DRIVER_DRUGS_PCT are changed most often; for the SVM, PEDESTRIAN_COUNT, DRIVERRF_4, and VEHICLECC_4 are changed most often. These changes show how the models respond to inputs. They do not establish causal effects.

Findings & limitations

  • Oversampling mainly helps the fatal class. Its F1 rises from 0.264 to 0.595, while the majority classes change little.
  • Both models often confuse minor and severe injuries, as the confusion matrices show.
  • Removing features based on the explanations did not improve performance. XGBoost test macro-F1 fell from 0.4843 to 0.4824. SVM validation macro-F1 fell from 0.5356 to 0.5321 after reducing the feature count from 163 to 55.
  • DiCE shows sensitivity near a model's decision boundary, not causes of injury severity. Missingness indicators such as *_UNKNOWN also affect predictions.
  • Future work could use more explicitly ordinal or cost-sensitive training, improve calibration for minority-class decisions, and add contextual features.
